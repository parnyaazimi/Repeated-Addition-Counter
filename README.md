# Repeated Addition Counter

A final project for the **Digital Logic** course, designed and simulated using **Proteus Design Suite**.

## 📌 About the Project

This project implements a digital logic circuit that takes two inputs, `m` and `n`, and displays successive multiples of `n` for `m` steps.

For example, for `m = 3` and `n = 5`, the expected output sequence is:

```text
5
10
15
```

The circuit demonstrates the application of digital logic components to arithmetic operations, comparison, and numerical display.

## 🎓 Course Project

- **Course:** Logic Circuits (LC)
- **Project Type:** Final Project
- **Design and Simulation Tool:** Proteus Design Suite

This project was developed as the final project of the Digital Logic course to apply concepts learned throughout the course in a practical circuit design.

## 📁 Project Files

## ▶️ How to Run

1. Open `Proj_7.pdsprj` in Proteus Design Suite.
2. Set the input values for `m` and `n`.
3. Run the simulation.
4. Observe the displayed multiples of `n`.
